# مصروفي

تطبيق مصاريف شخصي (PWA) بالعربي: تسجيل سريع، اليوم والشهر، السيولة، الدخل المتوقع، الالتزامات، التوقّع، ونصايح. كل البيانات على تلفونك بس (IndexedDB)، ما في سيرفر، وبشتغل بدون نت.

الرابط: https://hamootax-ai.github.io/masroofi/

## التثبيت على الآيفون (كروم)
1. افتح الرابط بكروم.
2. اضغط زر **المشاركة** ⬆️ جنب شريط العنوان.
3. اختار **"إضافة إلى الشاشة الرئيسية"** ← إضافة.
4. **افتح دايماً من الأيقونة.** البيانات بتنحفظ جوّا التطبيق المثبّت، وإذا فتحت الرابط من كروم بتلاقي نسخة فاضية ومنفصلة.

## النسخ الاحتياطي والاسترجاع
- الإعدادات ← **صدّر**: بيطلع ملف JSON. اختار "حفظ في الملفات" ← iCloud Drive.
- مفتاح Claude **مش** بالملف إلا إذا فعّلت "ضمّن مفتاح API".
- للاسترجاع: الإعدادات ← **استرجع** ← اختار الملف من Files. رح يسألك قبل ما يستبدل البيانات.
- الشاشة الرئيسية بتورجيك "آخر نسخة احتياطية"، وبتذكرك إذا صار أكثر من 7 أيام.

## مفتاح Claude (اختياري)
التطبيق كامل شغّال بدون مفتاح. المفتاح بس لـ "رأي كلاود" وتبويب "اسأل".
1. ادخل console.anthropic.com ← **API Keys** ← Create Key.
2. من **Settings ← Limits** حط حد صرف شهري (مثلاً 5$).
3. الصق المفتاح بالإعدادات بالتطبيق. فيك كمان تحط حد شهري جوّا التطبيق، وبوقف الإرسال لما يوصله.

**المفتاح بضل على تلفونك بس** (IndexedDB). مش بالكود ولا بالريبو، والطلبات بتروح من التلفون لـ api.anthropic.com مباشرة.

## كيف بينحسب كل شي
- المبالغ بتنخزن بالفلس (أعداد صحيحة) وبتنعرض بثلاث خانات: 13.150.
- **الصافي** = توفير + كاش − المطلوب على البطاقة. الدخل المتوقع وقيمة الأصول مش محسوبين.
- لما تكتب رصيد حقيقي لحساب، بيصير هو الأساس، وكل مصروف/تحويل بعده بينحسب عليه.
- مصروف بالبطاقة بيزيد المطلوب عليها وقت الشرا. **سداد البطاقة تحويل** من التوفير، مش مصروف، فما بينحسب مرتين.
- **دفعات الالتزامات والديون**: بتنقص الحساب اللي دفعت منه، بس **مش مصروف** بالشهر ولا بمعدل الصرف (لأن الالتزام نفسه محسوب بالتوقّع، فما بينحسب مرتين). تصنيف "سداد ديون" موجود للمصاريف الصغيرة اللي مش مسجلة كالتزام.
- **التوقّع** = السيولة هلأ + الدخل المتوقع قبل التاريخ − الالتزامات المستحقة قبله − معدل الصرف الشهري (آخر 3 شهور، أو الشهر الحالي إذا ما في تاريخ) × عدد الشهور. أسوأ حالة = بس الدخل الأكيد.
- **الرفاهية**: 60 بالشهر (بتتعدل). أصفر عند 75%، أحمر عند 100%. الصدقة ما بتنحكم.

## القفل
رمز 4 أرقام اختياري (محفوظ كـ SHA-256). قفل خفيف بيمنع الفتح بالصدفة، مش تشفير.

## تقني
HTML/CSS/JS بدون مكتبات ولا build. Service worker بيخزن كل الملفات (شغّال أوفلاين)، وأي تحديث بيوصل مع إعادة الفتح.

## رسائل البنك (v1.2)
- "سجّل" ← **رسائل البنك**: الصق رسالة أو أكثر، أو **استورد ملف الرسائل** (رسائل مفصولة بسطر `----`).
- بيفهم: إيداع بالتوفير، دفع فاتورة (المبلغ + العمولة)، تحويل كليك، سحب نقدي، ومشتريات/دفعات البطاقة.
- فاتورة مدفوعة بالبطاقة + رسالة البطاقة "at Housing Bank" بنفس المبلغ = **مصروف واحد** (حتى لو وصلوا بأوقات مختلفة).
- رصيد التوفير بيتحدث من "الرصيد المتوفر"، والمطلوب على البطاقة = الحد − "Available balance".
- الرسائل اللي انستوردت ما بتنعاد. مصاريف الكاش سجّلها بإيدك.
- الأتمتة: الاختصارات ← الأتمتة ← + ← الرسالة ← المرسل HousingBank (وكمان Iskan CrCrd) ← تشغيل فوري ← إلحاق بملف نصي: الرسالة + سطر جديد + `----` بالملف `iCloud Drive/Shortcuts/masroofi_sms.txt`.

## صندوق الرسائل التلقائي (v1.3)
كل رسالة من البنك بتنبعت لريبو خاص (private) على GitHub، والتطبيق بسحبها لما تفتحه (أو "اسحب هلأ")، بسجّل المؤكد لحاله، وبحط الباقي بـ "بدها مراجعة"، وبعدين بمسح الملف من الريبو.

**التوكن (مرة وحدة):** github.com ← صورتك ← Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token ← Expiration سنة ← Repository access: Only select repositories ← `masroofi-inbox` ← Repository permissions ← Contents: Read and write ← Generate ← انسخه. بالتطبيق: الإعدادات ← صندوق الرسائل التلقائي ← الصقه ← احفظ. التوكن بضل على التلفون بس.

**الأتمتة (iOS 18):** الاختصارات ← Automation ← + ← Message ← Sender: `HousingBank` ← Run Immediately (وطفّي Notify When Run) ← New Blank Automation، وبعدين الإجراءات:
1. Text ← Shortcut Input (Content).
2. Base64 Encode ← Line Breaks: None.
3. Format Date ← Current Date ← Custom: `yyyyMMdd-HHmmss-SSS`.
4. Get Contents of URL ← `https://api.github.com/repos/hamootax-ai/masroofi-inbox/contents/inbox/` + Formatted Date + `.txt` ← Method: PUT ← Headers: `Authorization` = `Bearer التوكن`، `Accept` = `application/vnd.github+json` ← Request Body: JSON: `message` = `sms`، `content` = Base64 Encoded.

وأتمتة تانية نفسها للمرسل `Iskan CrCrd`.

**شو بنسجل لحاله:** مشتريات البطاقة اللي تاجرها معروف، السحب النقدي، والفاتورة + رسالة البطاقة تبعتها (حتى لو وصلوا بسحبتين، بستنى لحد 30 دقيقة). **بدها مراجعة:** تحويلات كليك، الإيداعات، تجار مش معروفين (أخرى)، ورسائل مش مفهومة. الأرصدة بتتحدث من الرسائل فوراً. إذا فشل المسح، الرسالة ما بتنحسب مرتين.

## ملاحظة فيها كذا يوم (v1.7)
"سجّل" ← **📋 الصق ملاحظة اليوم**: الصق ملاحظة يوم واحد (زي قبل)، أو ملاحظة فيها شهور، كل يوم ببلّش بسطر تاريخ (`March 3`، `3 مارس`، `3/3`، وبيفهم غلطة حرف أو حرفين باسم الشهر).
- بيقسمها لأيام وبيورجيك: عدد الأيام، من لإيمتى، المجموع، وكل يوم (عدد البنود، مجموعه، و⚠️ إذا سطر Total غير مجموع البنود).
- "Rafaheyah" بسطر الـ Total لليوم كله: بعلّم البند (أو البنود) اللي مجموعها هيك رفاهية. إذا ما لقى، ما بعلّم شي وبحكيلك.
- سطور الدخل (`Plus ...` أو اللي بتخلص بـ `+`) وملخص الشهر (`March 2026 Expenses` + Total) ما بينضافوا كمصروف. الملخص بينفحص مقابل مجموع أيامه.
- بينضافوا بحساب **"ما تخصم من الحسابات"**: محسوبين باليوم والشهر والرفاهية، بس ما بيغيّروا أي رصيد.
- المكرر (نفس التاريخ والمبلغ والنص) بيتخطاه، فيك تلصق نفس الملاحظة مرة تانية بأمان.
- السنة: شهر بعد الشهر الحالي = السنة الماضية.

## إلي عند الناس (v1.7)
فلوسي ← **إلي**: مين، كم (رقم، أو نص زي `100-150` أو `حسب الحكم`)، متى متوقع (تاريخ أو نص)، أكيد ولا لأ، وملاحظة.
- المجموع فوق = بس اللي إله رقم. مش محسوب بالسيولة.
- بالتوقّع: بس اللي **أكيد** وإله رقم وتاريخ قبل تاريخ التوقّع (بالحالتين). الباقي مكتوب "مش محسوب".
- ✔️ وصلني: إذا خليت "ضيفه دخل على حساب" مفعّل، بينسجل دخل واصل على الحساب اللي بتختاره والرصيد بيزيد. ↩️ بيرجّعه (وبيشيل الدخل).

## استيراد بيانات (v1.7)
الإعدادات ← **📥 استيراد بيانات**: الصق JSON ← حلّل ← بيورجيك "رح أضيف: X دخل، Y التزام، Z إلك" ← ضيف.
**بيضيف بس**، ما بيمسح ولا بيستبدل شي. المكرر بالضبط بيتخطاه (فلو لصقت نفس الشي مرتين، المرة التانية ما بتضيف شي).
المبالغ بالدينار كأرقام (`100` أو `12.5`)، والتواريخ `YYYY-MM-DD`. كل قائمة اختيارية.

```json
{
  "incomes": [
    { "source": "مثال راتب", "amount": 100, "date": "2026-12-01", "recur": "monthly", "months": [], "sure": true }
  ],
  "obligations": [
    { "title": "مثال قسط", "amount": 100, "due": "2026-12-05", "priority": "mid", "monthly": false, "paid": 0 }
  ],
  "receivables": [
    { "who": "مثال", "amount": 100, "amountText": "", "expected": "2027-01-15", "sure": false, "note": "" },
    { "who": "مثال 2", "amount": null, "amountText": "100-150", "expected": "بعد الموسم", "sure": false, "note": "" }
  ]
}
```

| الحقل | المعنى | القيم |
|---|---|---|
| `incomes[].source` | مصدر الدخل (لازم) | نص |
| `incomes[].amount` | المبلغ (لازم) | رقم بالدينار > 0 |
| `incomes[].date` | الموعد المتوقع | `YYYY-MM-DD` (بدونه = اليوم) |
| `incomes[].recur` | بتتكرر؟ | `none` (الأساسي)، `monthly`، `yearly`، `months` |
| `incomes[].months` | مع `months` بس | أرقام الشهور 1..12، مثلاً `[3, 9]` |
| `incomes[].sure` | أكيد؟ (بس الأكيد بأسوأ حالة) | `true` (الأساسي) / `false` |
| `obligations[].title` | شو هو (لازم) | نص |
| `obligations[].amount` | المبلغ الكامل (لازم) | رقم بالدينار > 0 |
| `obligations[].due` | تاريخ الاستحقاق | `YYYY-MM-DD` أو `null` (بدون تاريخ = مش بالتوقّع) |
| `obligations[].priority` | الأولوية | `high`، `mid` (الأساسي)، `low` |
| `obligations[].monthly` | بيتكرر كل شهر بعد ما يخلص | `true` / `false` (الأساسي) |
| `obligations[].paid` | مدفوع منه قبل التطبيق (اختياري، ما بيغيّر رصيد) | رقم بالدينار |
| `receivables[].who` | مين (لازم) | نص |
| `receivables[].amount` | المبلغ | رقم بالدينار، أو `null` |
| `receivables[].amountText` | لما ما في رقم واحد | نص، مثلاً `100-150` |
| `receivables[].expected` | متى متوقع | `YYYY-MM-DD` أو نص حر (`due` كمان بياخد تاريخ) |
| `receivables[].sure` | أكيد؟ | `false` (الأساسي) / `true` |
| `receivables[].note` | ملاحظة | نص |

المكرر: دخل = نفس المصدر + المبلغ + التاريخ؛ التزام = نفس العنوان + المبلغ + الاستحقاق؛ إلك = نفس الاسم + المبلغ + النص + التاريخ.

## الضايل الآمن وأهداف التوفير (v1.8)
**💸 الضايل الآمن لليوم** (أول شي بالشاشة الرئيسية، اضغط عليه بيورجيك الحسبة):
دخل هالشهر (اللي وصل + الأكيد الجاي + "إلي" الأكيد) − التزامات هالشهر (المدفوع + الباقي لآخر الشهر) − حصة أهداف التوفير هالشهر − اللي صرفته هالشهر = **ضايل لآخر الشهر**، مقسوم على الأيام الباقية (مع اليوم) وناقص اللي صرفته اليوم.
- إذا ما في دخل مسجل لهالشهر، بياخد معدل دخلك (آخر 3 شهور، أو دخلك المتكرر الأكيد).
- ما بيطلع أكثر من الفلوس اللي معك فعلياً: الصافي + الجاي الأكيد − الالتزامات − المحجوز للأهداف.
- الرفاهية من ضمن الرقم. مصاريف البطاقة محسوبة وقت الشرا، وسدادها تحويل، فما بينحسب مرتين.

**🎯 أهداف التوفير** (الرئيسية ← أهدافي، أو الإعدادات): اسم، المبلغ، اللي معك منه، وموعد (اختياري) أو مبلغ شهري.
- بيحسب كم لازم تحط **بالشهر وبالأسبوع**، وقدرتك على التوفير (معدل الدخل − معدل المصروف − الالتزامات الشهرية).
- ➕ حطيت / ➖ سحبت: بس بتعلّم الفلوس محجوزة للهدف، **ما بيتحرك أي رصيد**. حصة الشهر بتنطلع من الضايل الآمن.
- الأهداف محفوظة مع باقي الإعدادات، فبتطلع بالنسخة الاحتياطية.

**التنبيهات:** ملاحظات "📈 التصنيف هالشهر فوق معدلك، شو صاير؟" صارت **مطفية**. بترجع من الإعدادات ← الشكل والتنبيهات.
**المظهر:** غامق (زي قبل)، فاتح، أو حسب التلفون.
